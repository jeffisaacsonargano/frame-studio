The world and storyline

Walk the Frame takes of the limit. Only the light version lives in the frame.

  • In the frame: the WebGL renderer, the frame and Blockflow levels, the warehouse and sources with SQL text (about 7 KB of SQL), Graphite, the hiring pads, ghost blocks and the field insight pad.
  • Artifact only (zero frame bytes): the office, the hiring floor characters, the call transcript animation, the street and shop, the CFO pitch and data center acts. Frame World in the artifact is about 236 KB on its own.
  • Rule of thumb: new story scenes go to the artifact; the frame gets a pad or plaque that points to them.

Keep as is

  • Dashboard views, Main Palette, Pulse and Edit layout: the reasons people open the frame.
  • Module host, approvals and writes: every write to Pigment goes through them. Versions and shared notes (about 11 KB) live here too.
  • Styles: already compact; full CSS minification would save only about 2 KB.

How this was measured

  • Sections are cut at the frame's own section markers; module boundaries are exact.
  • Where a section has no markers, its parts are listed by the largest functions, and a function's size runs to the next one, so those parts are approximate.
  • Full-line comments are stripped from the live body (done 25 Nov); a commented copy is kept in the archive as frame/lumina-pigment-frame.commented.js, which this map is measured from, so section sizes are approximate to within a few hundred bytes. Styles counts the CSS strings.
  • Re-run after each deploy: the archive repo holds the body as frame/lumina-pigment-frame.js.
